ТЕХНИЧЕСКОЕ ЗАДАНИЕ ДЛЯ ТРЕКИНГА (ФУНКЦИОНАЛ MVP)
-----------------------------------------------------------
Контент-агентство
- Боль: контент застревает между копирайтером, дизайнером и клиентом
- Роли: арт-директор, копирайтер, дизайнер, клиент
- Колонки: Идея -> Пишется -> Дизайн -> Согласование -> Опубликовано

1. РОЛИ И ПРАВА ДОСТУПА

Роль: Арт-директор (админ)
- Видит: все задачи, все клиенты, все колонки
- Может: создавать задачи, назначать исполнителей, двигать по доске, фильтровать по клиентам

Роль: Копирайтер
- Видит: задачи, где он исполнитель + колонка «Идея»
- Может: двигать свои задачи, добавлять текст/ссылки

Роль: Дизайнер
- Видит: задачи в колонках «На дизайне» и далее
- Может: двигать свои задачи, прикреплять макеты

Роль: Клиент (внешний)
- Видит: только колонка «На согласовании» по своим проектам
- Может: оставлять комментарии «Принято» / «Правки»


2. КОЛОНКИ КАНБАН-ДОСКИ

1. Идея — черновики тем, ещё не распределены
2. Пишется — у копирайтера в работе
3. Текст готов — ждёт передачи дизайнеру
4. На дизайне — у дизайнера в работе
5. На согласовании — отправлено клиенту
6. Опубликовано — финальная стадия


3. ПОЛЯ КАРТОЧКИ ЗАДАЧИ

- Название (обязательно)
- Клиент (выпадающий список: 5 клиентов) — обязательное поле
- Тип контента: Пост / Статья / Рассылка / Видео
- Исполнитель (копирайтер или дизайнер)
- Дедлайн публикации
- Ссылка на текст / макет
- Статус согласования (только для колонки «На согласовании»)


4. ПРАВИЛА ПЕРЕХОДОВ

- Из «Идея» в «Пишется» — только арт-директор назначает копирайтера
- Копирайтер двигает: «Пишется» -> «Текст готов»
- Арт-директор проверяет и двигает: «Текст готов» -> «На дизайне» (назначает дизайнера)
- Дизайнер: «На дизайне» -> «На согласовании»
- Клиент: «На согласовании» -> «Опубликовано» или возврат с правками
- Возврат с правками — автоматически создаёт комментарий с текстом клиента


5. ФИЛЬТРЫ И СВОДКИ

- Фильтр по клиенту (5 клиентов)
- Фильтр по исполнителю
- Сводка «Узкие места»: в какой колонке больше всего задач
